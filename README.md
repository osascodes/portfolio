# Benjamin Osahon — Portfolio

One-page freelance full-stack portfolio. Next.js 15 + Tailwind CSS 4.

Primary experience is the homepage with All / Frontend / Full stack filters.
Optional routes: `/work`, `/work/[slug]`, `/about`, `/contact`.

No personal photo. WhatsApp + Web3Forms contact.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

Import this repo in [Vercel](https://vercel.com/new). Point osastech.com.ng when ready.

Edit copy in `src/data/site.ts` and `src/data/projects.ts`.
